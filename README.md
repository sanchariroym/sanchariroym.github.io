# sanchariroy.com

Personal academic website of Sanchari Roy, built with Jekyll and published by GitHub Pages.

## Editing

Each page is a Markdown file:

| Page | File |
|---|---|
| Home | `index.md` |
| Research | `research.md` |
| Grants | `grants.md` |
| Teaching | `teaching.md` |
| Workshops | `workshops.md` |
| Media and Policy Writing | `media-and-policy-writing.md` |

To edit on github.com: open the file, click the pencil icon, make the change, then click **Commit changes**. The live site updates within a minute or two.

The menu is set in `_config.yml` (under `nav`). The portrait lives at `assets/images/sanchari-roy.jpg`.
